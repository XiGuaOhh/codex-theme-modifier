## v2.1.1 更新退出回归

实际检查中，旧版窗口退出时维护器报错；下载哈希及目标身份验证通过，父进程完全退出后重放同一维护任务成功。新增测试保留一个已经退出的真实子进程对象，调用旧进程等待逻辑，稳定复现 `Win32Exception`：仅完成部分 ReadProcessMemory 或 WriteProcessMemory 请求。

修复后先检查进程是否退出，并使用 `QueryFullProcessImageName` 读取仍存活进程的路径，不再枚举其模块。37 项检查通过，覆盖已经退出、正常等待、错误父进程路径、等待超时及不强制结束父进程。维护器失败时会将阶段、异常类型和消息保存到临时维护目录中的 `maintenance-error.json`，不包含聊天内容或账号凭据。

公开的 v2.1.1 发行程序已完成在线下载和 SHA-256 验证。随后在真实安装中运行生产维护器，父进程发出更新任务后立即退出：维护任务成功完成并移除任务文件，安装版自动重新打开，未产生错误记录。安装版本和卸载登记更新为 v2.1.1，自动检查更新及背景启用状态保留，原先 16 个官方 Codex 进程全部继续运行。实际窗口确认背景预览及原有透明度参数保留，设置页更新按钮与开关显示正常。

## 自动检查

`tests.ps1` 的 31 项检查使用模拟安装环境，不改动真实的开始菜单或卸载登记，覆盖：

- 资源部署、启用标记、快捷方式和卸载登记调用。
- 图片复制、参数范围、未应用图片的保留与修订号确认。
- 关闭时保留设置、卸载后保留设置、重新安装。
- 明确删除设置后再次安装，不会重新读入旧的应用内背景；没有本地设置文件时同样记录重置请求。
- 用户已更改的快捷方式保留、旧主题入口恢复官方应用。
- 越界路径和错误安装实例拒绝，删除设置仅作用于本项目的文件。
- 错误更新校验值拒绝且旧版本保留，合法更新只替换修改器。
- GitHub 版本和校验值解析、其他仓库和明文 HTTP 拒绝、预发布排除。
- 中文调试响应使用 UTF-8，独立聊天窗口允许，头像和插件页面排除。
- 模拟官方程序文件从安装至卸载的哈希保持一致。

## 范围与局限

这些检查证明当前版本的主要安装、加载、移除和更新校验行为。它们不构成所有模型、账户类型、插件、网络环境、分辨率及未来官方版本的完整回归测试。

背景适配依赖官方页面的结构与样式变量。未来版本可能需要更新选择器，官方安装身份和更新入口保留也不意味着所有第三方主题效果永远兼容。出现外观问题可关闭主题并从官方入口启动。

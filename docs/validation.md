## 自动检查

`tests.ps1` 的 31 项检查使用模拟安装环境，不改动真实的开始菜单或卸载登记，覆盖：

- 资源部署、启用标记、快捷方式和卸载登记调用。
- 图片复制、参数范围、未应用图片的保留与修订号确认。
- 关闭时保留设置、卸载后保留设置、重新安装。
- 明确删除设置后再次安装，不会重新读入旧的应用内背景；没有本地设置文件时同样记录重置请求。
- 用户已更改的快捷方式保留、旧主题入口恢复官方应用。
- 越界路径和错误安装实例拒绝，删除设置仅作用于本项目的文件。
- 错误更新校验值拒绝且旧版本保留，合法更新只替换修改器。
- GitHub 版本和校验值解析、其他仓库和明文 HTTP 拒绝、预发布排除。
- 中文调试响应使用 UTF-8，独立聊天窗口允许，头像和插件页面排除。
- 模拟官方程序文件从安装至卸载的哈希保持一致。

## 实机检查

`native-tests.ps1` 的 18 项检查使用独立的浏览器资料目录和加载器，覆盖：

- 保留注册官方应用身份，测试进程与原来已运行的进程分离。
- 随机本机端口的进程与会话验证，主窗口筛选。
- 主题控件只加载一次，图片与透明度参数实际生效。
- 官方桥接对象和浏览器 API 引用保持一致。
- 中文窗口标题在调试目标列表中正确往返。
- 文件设置已应用的修订确认。
- 停用后加载器正常退出，主题样式和控件即时移除。
- 关闭主题后刷新窗口不会重新注入，官方运行环境仍然可用。
- Windows 应用 Shell 快捷方式可以创建并恢复。
- 官方可执行文件和 `app.asar` 在检查前后的 SHA-256 一致。
- 原来已经运行的 Codex 进程保持运行。

## 范围与局限

这些检查证明当前版本的主要安装、加载、移除和更新校验行为。它们不构成所有模型、账户类型、插件、网络环境、分辨率及未来官方版本的完整回归测试。

背景适配依赖官方页面的结构与样式变量。未来版本可能需要更新选择器，官方安装身份和更新入口保留也不意味着所有第三方主题效果永远兼容。出现外观问题可关闭主题并从官方入口启动。

GitHub 在线发行与下载验证在首次发布时另外执行；自动测试不携带 GitHub 账号或访问令牌。
